# Tracking

Portable, plain-text mastery tracking for every problem you attempt.

## Files

| File | Purpose |
|---|---|
| `problem_tracker.csv` | Source of truth. One row per problem. |
| `review_queue.md` | Generated by `scripts/generate_review_queue.py`. |
| `topic_progress.md` | Generated by `scripts/generate_progress_report.py`. |
| `schemas/problem_tracker.schema.json` | Column definitions and validation rules. |

## Columns

See [`schemas/problem_tracker.schema.json`](schemas/problem_tracker.schema.json)
for the authoritative schema. Summary:

| Column | Notes |
|---|---|
| `problem_id` | Slug, unique. |
| `problem_name` | Human-readable title. |
| `source` | `neetcode`, `leetcode`, `course`, `book`, `other`. |
| `problem_url` | Optional. |
| `topic` | e.g. `arrays-and-hashing`, `two-pointers`. |
| `subtopic` | Optional finer category. |
| `difficulty` | `easy`, `medium`, `hard`, `n/a`. |
| `language` | `python`, `cpp`, etc. |
| `status` | `unsolved`, `in-progress`, `solved`, `retired`. |
| `mastery_level` | `0`–`5`, see below. |
| `first_attempt_date` | `YYYY-MM-DD`. |
| `solved_date` | `YYYY-MM-DD` or empty. |
| `last_review_date` | `YYYY-MM-DD` or empty. |
| `next_review_date` | `YYYY-MM-DD` or empty. |
| `attempt_count` | Integer. |
| `time_complexity` | e.g. `O(n)`. |
| `space_complexity` | e.g. `O(1)`. |
| `solution_path` | Repo-relative path or empty. |
| `notebook_path` | Repo-relative path or empty. |
| `notes` | Free text (no commas — use `;` or escape). |

## Mastery scale

| Level | Meaning |
|---|---|
| 0 | Unsolved — no valid approach yet. |
| 1 | Assisted — solved with substantial help. |
| 2 | Understood — can explain but not reproduce. |
| 3 | Independent — can solve without looking. |
| 4 | Mastered — solves efficiently, explains trade-offs. |
| 5 | Transferable — can recognize and apply the pattern elsewhere. |

## Review intervals

Configurable in `scripts/generate_review_queue.py`. Defaults:

| Mastery | Next review in |
|---|---|
| 0 | 1 day |
| 1 | 1 day |
| 2 | 3 days |
| 3 | 7 days |
| 4 | 21 days |
| 5 | 45 days |
